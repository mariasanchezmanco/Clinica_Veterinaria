Descripción del proyecto

Este proyecto consiste en un sistema de consola desarrollado en Java para gestionar las operaciones básicas de un hospital veterinario. Permite registrar pacientes de diferentes tipos, asignar jaulas según sus características, administrar medicamentos y gestionar el alta de los pacientes.

 ¿Cómo lo hice?

Desarrollé este proyecto en Java utilizando IntelliJ IDEA y aplicando los principios de la programación orientada a objetos. Para organizar el código, creé diferentes clases con responsabilidades específicas y utilicé herencia, encapsulamiento y arreglos de tamaño fijo.

Durante el desarrollo, conté con el apoyo de ChatGPT como herramienta de inteligencia artificial, que me ayudó a comprender los requisitos del proyecto, organizar las clases, orientar la implementación de las reglas de negocio y resolver dudas sobre el código.

A partir de estas orientaciones, trabajé en la implementación del sistema, revisé su funcionamiento y realicé pruebas en la consola para comprobar el registro de pacientes, la asignación de jaulas, la administración de medicamentos y el alta veterinaria.

La interacción con el usuario se realiza mediante comandos en consola, utilizando `Scanner` para leer los datos y `System.out` para mostrar los resultados. La información se almacena en arreglos durante la ejecución del programa, sin utilizar bases de datos ni archivos externos.
